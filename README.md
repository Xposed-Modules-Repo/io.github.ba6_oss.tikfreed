# TikFreed

TikFreed 是一款面向 **TikTok 国际版** 的 LSPosed 模块，用于调整 TikTok 运行时的区域相关环境参数，
并隐藏界面中的广告与干扰元素。

**作用域**：`com.zhiliaoapp.musically`、`com.ss.android.ugc.trill`、`com.ss.android.ugc.musically.go`
**Xposed API**：libxposed `minApiVersion=102` / `targetApiVersion=102`（需要支持 API 102 的 LSPosed）
**版本**：1.0.1（versionCode 2）｜ **日志 tag**：`TikFreed`

## 功能

### 区域环境
- **SIM 国家码**：调整 SIM 国家/地区标识
- **网络国家码**：调整网络国家/地区标识
- **运营商信息**：模拟运营商名称与编号
- **系统语言**：切换到目标地区的语言环境
- **系统时区**：切换为目标地区的时区
- **GPS 位置**：调整应用获取到的经纬度

### 界面净化
可逐项开关，隐藏广告位、推广卡片、优惠券、观看历史推荐等干扰内容。
每项支持多候选资源 id，并带语义兜底（文案/描述匹配），适配不同 TikTok 版本。

### 其他
- **播放增强**：长按倍速（1.25x / 1.5x / 2x / 3x）、清晰度、循环播放等
- **评论翻译**：基于 MyMemory / Google 翻译接口
- **IP 国家联动**：根据出口 IP 自动匹配目标地区
- **外观**：浅色 / 深色 / 跟随系统，8 种主题色
- **配置管理**：导出 / 导入、多套方案切换、单项重置
- **启动器图标隐藏**：隐藏后可通过快捷设置磁贴进入

## 使用步骤

1. 安装 LSPosed（需支持 API 102）
2. 在 LSPosed 中启用 **TikFreed**
3. 将 TikTok 国际版加入作用域（`com.zhiliaoapp.musically`）
4. 打开 TikFreed，选择目标地区
5. **完全结束并重启 TikTok**（从最近任务划掉）
6. 打开 TikTok 检查效果

## 注意事项

- 需要 LSPosed **API 102** 及以上
- 修改设置后必须**重启 TikTok** 才能生效
- 实际效果受 TikTok 版本、账号、网络环境影响
- 出口 IP 由国家/地区由服务端判定，模块无法修改

## 隐私

- 模块主要在本地运行，不主动上传个人信息
- 评论翻译会把待翻译文本发送至第三方翻译服务（MyMemory / Google）
- IP 国家探测会访问公开的 IP 归属查询服务
